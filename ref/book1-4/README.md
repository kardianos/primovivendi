# Primary Sources Reference Collection

> **Moved 2026-11-10** from `book1-4/ref/`. This folder (`ref/book1-4/`) holds the README, logs, research-gap notes, and the public-domain USA texts. Third-party copies are in `ext-ref/book1-4/` at the repo root, under the same subfolder names, and are not committed. Paths in `SOURCE_LOG.txt` are relative to whichever of the two folders holds the file.

This folder contains primary source materials collected for the book's narrative case studies:

- **USA** (Focus case study) — American Founding and the principles behind the Constitution
- **Russia** (Mirror case study) — Late Tsarist reforms through the 1917 revolutions
- **Iran** (Mirror case study capstone) — 1979 Revolution and the Marxist-Islamist alliance + subsequent purge
- **Singapore** (Positive narrative model) — Lee Kuan Yew and the building of modern Singapore

## Purpose

These materials exist so that all historical claims used in the book can be:
- Verified locally by anyone working on the project
- Cited accurately with stable references
- Traced back to original documents rather than secondary interpretations

## Rules for This Collection

1. **Primary first**: Prefer original documents, official records, letters, speeches, government reports, and participant memoirs over secondary histories.
2. **Local copies**: All files here are the authoritative local versions. Do not rely on live websites for verification.
3. **Citable**: Every item must have a clear, standard citation format suitable for the final book.
4. **Language transparency**: For non-English sources, note the original language and whether any translation was performed locally.
5. **Logging**: All acquisitions must be recorded in `SOURCE_LOG.txt` with source location, date, and notes.
6. **Verification standard**: A future researcher should be able to locate the exact same document using only the information in this log.

## How to Add New Material

1. Place the file in the appropriate subfolder.
2. Add a complete entry to `SOURCE_LOG.txt`.
3. If the source is in a non-English language, note the original + any translation details.
4. Prefer stable archives (National Archives, Internet Archive, official government sites, academic repositories) over random websites.

## Current Focus Areas

- **USA**: Founding documents and correspondence showing the actual aims behind the Revolution and Constitution (truth as consequential, procedural symmetry, human limits, tiered responsibility).
- **Russia**: Evidence of both ongoing despotism and genuine reform efforts in the late Tsarist period (especially 1905–1917), plus the consequences after the Marxist victory.
- **Iran**: Primary materials from Khomeini’s circle and from Marxist/leftist groups (Tudeh, etc.) during 1978–1983, especially around the tactical alliance and later purge.
- **Singapore**: Lee Kuan Yew’s own writings and major policy speeches that demonstrate deliberate application of the five principles.

This collection supports the principle that stories and historical examples are used to **exemplify** the five principles and their inversions — they are never used to derive or prove those principles.

## Updated Collection Policy (as of 2026-05-15)

The original strict "primary sources only" rule has been relaxed by user direction to improve coverage of effects, outcomes, and quantitative data.

**New rules:**

- **Primary sources remain preferred.** Official documents, government statistics, letters, speeches, and participant memoirs are still the highest priority.
- **Reliable secondary sources are now allowed.** Well-researched academic books, scholarly articles, and reputable reproductions of primary data (e.g., statistical tables from censuses or yearbooks reproduced in academic works) may be included when direct primary files are difficult to obtain.
- **Placeholder references for hard-to-download items.** When a high-value source cannot be easily downloaded as a local file (paywalled, requires library access, very large scans, etc.), create a `.txt` placeholder file in the appropriate subfolder containing:
  - Full citable name and author
  - Exact location / archive / URL where it can be found
  - Brief description of why it is useful (e.g., contains pre/post literacy rates, Shah’s personal assessment, etc.)
  - Any known access method (e.g., “available via National Library Board Singapore digital collection”)
- The goal is pragmatic completeness: we want to be able to cite strong evidence for the effects and direction of events, even if some materials require manual retrieval by the user.

All new entries (whether full files or placeholders) must still be logged immediately in `SOURCE_LOG.txt` using the established format.

This policy change was made to better support the need for pre/post quantitative data and the Shah’s perspective on the Iranian case study, while maintaining verifiability.
